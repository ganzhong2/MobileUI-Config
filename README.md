## 这个软件能做什么

- **自定义虚拟按键**：在手机 / 平板预览框里拖拽摆放按键，每个按键独立绑定键盘键、鼠标按键或滚轮，支持**短按、长按、双击**三套独立触发。
- **摇杆与视角**：左侧走位摇杆 + 独立视角操控区域，支持死区、灵敏度、响应曲线、外形尺寸与透明度调节，摇杆四方向按键可自行录制绑定。
- **多套布局模式**：最多 12 个模式，可通过**图片识别**或**内存扫描**在游戏进入不同界面时自动切换布局。
- **虚拟手柄**：独立的虚拟手柄配置页，内置微软 Xbox、索尼 DualShock、任天堂 Switch Pro 三套经典布局，经 ViGEmBus 模拟成真实 Xbox 360 / DualShock 手柄上报给游戏。
- **自动跳过剧情**：按顺序或随机识别剧情对话框截图，自动点击继续按钮。
- **多游戏独立配置**：每个游戏一套独立 XML，支持导出 `.mobui` 分享包在另一台电脑导入恢复。
- **触屏 / 鼠标双模输入**：悬浮层同时响应串流触屏和本地鼠标，带去重、防抖、残留按键兜底释放。
- **后台驻留**：单实例运行，游戏在前台才激活悬浮层，切后台自动挂起并释放全部输入。

> 虚拟按键页与虚拟手柄页是**两套完全独立、各自保存、互不干扰**的配置；摇杆、视角、系统按键动作都按页面独立记录。

## 两个版本怎么选

| 项目 | 标准版 `MobileUI-Config-Standard-v1.0.0.exe` | 独立版 `MobileUI-Config-SelfContained-v1.0.0.exe` |
| --- | --- | --- |
| 运行时 | 使用系统自带 **.NET Framework 4.8** | 内置 **.NET 8** 运行时，无需另装运行库 |
| 体积 | 约 570 KB（另带 `ViGEmClient.dll`） | 约 63 MB（单文件自包含） |
| 适用系统 | 已装 .NET Framework 4.8 的 Windows 10 / 11 | Windows 10 1607+ / Windows 11（64 位） |
| 推荐场景 | 电脑环境干净、追求小体积 | 不想折腾运行时、拿到就能用 |

两个版本功能完全一致，只是打包方式不同。发布目录 `dist/v1.0.0/` 内同时附带 `ViGEmClient.dll`，**必须与 exe 放在同一文件夹**，删除或缺失会导致虚拟手柄功能不可用（键鼠映射不受影响）。

## 安装环境与驱动

### 1. 操作系统与运行时

- **独立版**：Windows 10 1607 及以上 / Windows 11，64 位；内置 .NET 8，无需安装运行库。
- **标准版**：需要系统已安装 **.NET Framework 4.8**（Windows 10 1903 之后、Windows 11 默认自带；老系统可从微软官网下载安装）。
- 程序清单要求**管理员权限**：启动时会弹出 UAC 确认框，这是为了向同样以管理员身份运行的游戏窗口注入按键；没有管理员权限时，对提权游戏的输入会被 Windows 的 UIPI 机制拦截。

### 2. ViGEmBus 驱动（仅虚拟手柄功能需要）

- 使用**虚拟手柄**页前，需要安装开源的 [ViGEmBus](https://github.com/nefarius/ViGEmBus) 驱动：到其 Releases 页面下载 `ViGEmBus_Setup.exe`，按向导安装后重启即可。
- **不装 ViGEmBus 也能正常使用虚拟按键（键鼠映射）**；驱动或 `ViGEmClient.dll` 缺失时，手柄注入会静默降级，不影响键盘鼠标旧链路，程序不会崩溃。
- 程序内「ViGEmBus / HID」两个通道互斥：ViGEmBus 通道走 Xbox 360（XInput），HID 通道走 DualShock 4 标准 HID 设备，二者由 ViGEmBus 总线接管。

### 3. SmartScreen 与解压说明

- 本程序是**未做数字签名**的个人免费作品，首次运行时 Windows SmartScreen 可能弹出蓝色提示：点击「**更多信息 → 仍要运行**」即可。
- 建议把整个发布文件夹解压到**固定本地目录**（不要放在压缩包内直接运行、不要放系统保护目录）；路径尽量避免生僻特殊字符。
- 首次运行建议右键「以管理员身份运行」一次，后续由清单自动申请权限。

### 4. 游戏窗口建议

- 优先使用游戏内的**无边框全屏（Borderless Fullscreen / 窗口化全屏）**。真正的 DirectX 独占全屏会由显卡直接接管显示，普通置顶窗口在多数独占全屏游戏中无法绘制悬浮层或接收点击，这不是输入代码能完全绕过的限制。
- 游戏与本程序建议放在同一权限级别运行，避免一边管理员一边普通用户导致输入被拦截。

## 快速上手

1. 解压 `dist/v1.0.0/` 整个文件夹，确认 exe 与 `ViGEmClient.dll` 在同一目录；需要虚拟手柄时先装好 ViGEmBus 驱动。
2. 右键以管理员身份运行 exe；在顶部「程序路径」选择游戏的 exe（或 `.bat` / `.cmd` / `.lnk`），需要时填写启动参数，点击「启动游戏」。
3. 在左侧手机预览框里拖拽摆放按键，右侧面板绑定键盘 / 鼠标 / 手柄按键；布局自动保存，游戏前台时悬浮层自动出现。

## 使用指南

### 顶部启动区域

- **项目名称**：点击标题栏下方的「移动端UI」文字直接改名，自动保存。
- **程序路径**：支持浏览选择、粘贴路径、把文件拖入路径框；支持 `.exe / .bat / .cmd / .lnk`。
- **启动参数**：可填写 `-windowed -dx11` 等任意命令行参数。
- **启动游戏**：按当前路径和参数启动程序，工作目录设为程序所在目录；默认在启动后把设置窗口最小化到任务栏（任务栏按钮保留，不退出程序、不隐藏到托盘）。
- **本地模式 / 串流模式**：标题栏右侧两个独立开关——两个都开时本地游戏和串流会话都显示虚拟界面；只开其中一个则仅对应环境显示。
- **开机后台待命**：开启后写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 后台启动项，登录 Windows 后程序静默驻留托盘，检测到游戏 / 串流会话自动加载悬浮层，可随时关闭。

![启动卡片](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/launch.png)

### 多游戏配置与分享

- 顶部显示当前游戏名，「游戏配置」栏列出已保存的游戏标签。
- 设置好路径后点「**保存游戏**」，弹窗自定义名称；点标签右侧「+」新建一个全新游戏配置，新标签排在已有标签右侧。
- 切换其他游戏标签时，会先自动保存当前游戏的路径、参数、按键布局、识别图片、内存搜索、剧情跳过等全部设置；每个游戏各自独立，来回切换不丢失。
- 特征图、剧情跳过图、按键图标、音效按游戏隔离：运行时活动资源放在 exe 目录下与游戏同名的专属文件夹（内含 `key_images\`、`sounds\` 子目录）；另在 `games\assets\<配置名>\` 保存一份图片镜像，供切换游戏、导入分享包时恢复。按键布局、模式、摇杆、视角与识别参数各自保存在 `games\` 下的独立游戏 XML 中。
- 只有配置真正发生变化时才写入 XML，没修改不会反复覆盖文件。
- **导出**：点「导出」按钮，或右击游戏标签，可导出 `.mobui` 分享包，内含全部模式、按键布局、位置、长短按、摇杆、视角、自动切换设置、本地 / 串流开关、剧情跳过设置、按键图标与全部特征 / 跳过截图。在另一台电脑「**导入**」`.mobui` / `.zip` 即可整体恢复。
- 右击游戏标签菜单还包含「重命名」「导出配置」「创建快捷方式」：桌面快捷方式直接加载该配置并启动游戏本体；程序已在运行时，快捷方式会把请求转给现有实例，不会重复打开。

### 系统按键（显示键 / 模式键）

手机预览上方为系统按键设置条，分别管理 **显示键** 和 **模式键**，各自有独立启用开关，且**虚拟按键页与虚拟手柄页的动作独立保存**：

- **显示键**：可分别设置短按、长按、双击动作——无 / 切换显示隐藏 / 显示按键 / 隐藏按键 / 进入移动 / 拦截鼠标点击 / 跳过剧情。默认短按「切换显示 / 隐藏」，长按「进入移动」，双击「无」，因此只有长按才进入拖拽布局状态。
- **模式键**：短按、长按、双击可分别绑定 无 / 模式选择菜单 / 模式一至模式 N；例如短按模式一、长按模式五、双击模式菜单。
- 模式下拉名称跟随上方模式标签实时更新，新增模式后自动出现对应选项。设置条底部实时显示当前动作摘要。
- 除上述动作外，显示键还可绑定：**拦截鼠标点击**开关、**开启 / 关闭跳过剧情**等运行时动作；切换后屏幕正中央会弹出汉字提示说明当前状态。

### 模式与横竖屏

- 默认 **模式一 ~ 模式五**，显示在预览框上方；点「添加」新增模式（最多 12 个），每个模式有独立按键布局。
- 双击模式标签修改名称，名称会同步到悬浮层「模式」菜单。
- 点任意模式标签后，右侧设置区立即切换为该模式的按键。
- 右上角「切换为竖屏 / 横屏」控制预览方向，保存到配置并在悬浮层沿用。

![竖屏预览](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/portrait.png)

### 手机预览框

- 直接拖拽任意虚拟按键、摇杆、方向键调整位置，松开自动保存；**无需先进入移动模式**，预览界面即可随意拖动。
- 位置按屏幕比例保存，窗口尺寸变化不会破坏布局。
- 预览框上方两个系统按键：
  - **显示 / 隐藏 / 移动**：点击循环切换。`显示`=全部按键显示；`隐藏`=除该键外全部隐藏（未勾选「跟随隐藏模式隐藏」的按键仍显示）；`移动`=所有按键重新显示并进入拖拽布局。
  - **模式**：点击后在按键下方弹出模式菜单，选择后切换布局并自动收起。
- 所有按键、系统键、模式标签和开关都有按压高亮 / 遮罩反馈。
- 左侧整栏（预览 + 摇杆 + 视角 + 自动切换模式）共用垂直滚动页，鼠标滚轮在画面或设置区都可上下滚动。

### 摇杆设置（虚拟按键页）

预览框下方是可上下滚动的控制面板，依次为摇杆、视角操控、自动切换模式：

- **摇杆大小**：整体操作区直径，范围 80 ~ 500 px，默认 250 px；**外圈大小**底盘直径默认 200 px；**内圈大小**摇杆头直径默认 84 px。
- **不透明度**：10% ~ 100%，默认 70%。
- **死区**：0 ~ 40（半径占外圈半径百分比），默认 12，死区内不产生方向输入。
- **灵敏度**：50 ~ 200，默认 100，按比例放大 / 缩小输出长度。
- **响应曲线**：线性 / 加速（凸）/ 减速（凹）/ S 型四种；**弯曲度** 0 ~ 100，默认 50，0 接近线性、100 曲线最陡。
- **方向绑定**：上 / 下 / 左 / 右四个方向均可独立录制为键盘键、鼠标键或滚轮；默认未绑定，需在面板中自行设置。
- 摇杆在预览与悬浮层都有中心弹簧回弹、按下发光、方向键高亮和外圈刻度反馈；实际悬浮层按八方向输出，支持斜向组合按键。
- **显示模式**：一排模式开关，单独控制每个模式是否显示摇杆，模式名称跟随上方模式条。

### 视角操控（虚拟按键页）

摇杆设置下方为视角操控，用于在触屏上模拟鼠标拖动视角：

- **独立启用开关**，默认启用；关闭后预览和悬浮层都不显示。
- **形状**：圆形 / 方形 / 长方形；圆形和方形自动等宽高，长方形可分别设置宽高。默认 210 × 210，范围 60 ~ 900；**不透明度**默认 65%。
- **鼠标键**：左键 / 右键 / 中键 / 侧键 1 / 侧键 2，默认右键。
- **消息注入（全屏兼容）**：开启后不再移动物理光标，而是维护虚拟光标并用 `PostMessage` 向游戏 / 串流窗口发送按下、移动、抬起消息；适合物理鼠标被独占全屏锁死的情况。关闭时使用 `SendInput` 真实鼠标注入。
- **灵敏度**：1.0x ~ 20.0x（内部数值 100 ~ 2000），默认 1.0x。
- 手指按住后上下左右滑动，会按住选定鼠标键并持续发送相对移动，松开释放鼠标键；串流模式下以当前串流客户端窗口作为坐标范围。
- **显示模式**：单独控制每个模式是否显示视角操控。
- 绑定设为「无」时不会残留鼠标按下，避免上一会话未抬起导致的长按普攻 / 技能。

### 自动切换模式一 · 图片识别

「自动切换模式一 · 图片识别」面板在视角操控下方：图片项目列表挂在当前页面配置根上，虚拟按键页与虚拟手柄页各自独立保存；项目列表与界面预览的模式（Modes）相互独立，每个项目通过「目标模式」指向要切换到的界面模式，最多可添加 12 个图片项目。

- **一个横条、三个特征槽**：最左侧按序排列「特征一 / 特征二 / 特征三」缩略图，点击选中（描边、标签变色），右侧「选择 / 截图 / 清除」作用于当前槽。
  - 「选择」打开文件管理器选 png / jpg / jpeg / bmp，随后弹出裁剪窗口；「截图」通过按钮或 `F8` 全屏框选；建议裁切 **60–320 px**。
- 三张图可只设一张，也可设两张 / 三张；没设图片的槽不参与识别。
- **识别规则**：
  - **随机**：任意一张已设置特征图被识别到，就立即切换到目标模式；
  - **交叉**：所有已设置特征图必须同时命中才切换；只设一张时命中即切换。
- **目标模式**：三张图共用的唯一目标模式。面板右上角开关控制当前图片项目是否启用。
- **截图快捷键**：默认 `F8`，当前页面各图片项目共用；仅当设置窗口隐藏到托盘或最小化、且游戏处于前台时才注册生效；截图保存为 `feature{项目}_{槽}.png`。
- **识别方式**：彩色 HSV 色块命中率 + 边缘梯度结构 NCC 双路融合，13 档等比缩放覆盖窗口与分辨率波动；设置锚点后只在锚点邻域搜索以提速。每个图片项目可独立配置：命中次数（1 ~ 5 次，默认 1 次，切换后巩固窗口内反向回切至少连续 2 次）、切换后冷却（默认 2000 ms，可配 0 ~ 10000 ms）、相似度阈值（默认 0.85）；扫描间隔取首个启用项目的设置（200 ~ 3000 ms，默认 400 ms）。
- 识别只在游戏进程运行或检测到串流会话、且设置窗口不在屏幕前台时轮询。

![图片识别](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/auto-mode.png)

### 自动切换模式二 · 内存扫描

「自动切换模式二 · 内存扫描」在图片识别下方，项目列表同样挂在当前页面配置根上、与界面预览的模式解耦；最多 12 个项目，每个项目配置一条内存地址规则：

- **单个内存地址**：基址 + 偏移 + 目标值。
- **基址**支持：`模块名+偏移`（如 `GameAssembly.dll+0x1A2B3C`）、绝对地址（如 `0x7FF6A1234567`）；留空表示游戏主模块基址。
- **偏移**用逗号、分号或空格分隔，如 `0x10,0x20,0x8`，按指针链逐级读取。
- **目标值**支持十进制或 `0x` 十六进制；留空表示最终值非 0 即命中。
- 命中后切换到「命中后切换到」选择的目标模式；开关控制当前内存项目是否启用，扫描间隔全局共用（50–1000 ms）；同一目标连续命中两次才切换，切换后 1.2 秒冷却。
- 内存扫描在程序启动后即可开启，不要求先启动游戏，会持续等待配置路径中的游戏进程出现。

![内存扫描](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/memory-scan.png)

> **内存识别可能被游戏反作弊判定为违规，存在封号风险，请谨慎使用。**

![内存识别免责声明](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/memory-warning.png)

游戏进程识别规则：同时识别「程序路径」对应的 exe 文件名与面板里手动填写的游戏进程名（多个用逗号、分号或空格分隔）；游戏已经在任务管理器运行、不是由本程序启动，也能被识别。游戏进程结束后默认自动退出本程序，可在托盘菜单关闭「游戏结束后自动退出」。

### 自动跳过剧情

最底部「自动跳过剧情」：

- **本地模式 / 串流模式**：两个独立开关，决定哪种环境启用自动跳过；**始终开启**独立开关，开启后无视上述两个开关始终生效。
- **选择**：打开文件管理器选图后弹出裁剪窗口，拖动框选后保存，建议 60–320 px。
- **图片一 / 二 / 三**：每个目标行有三个可点击图片槽，点击高亮后「选择 / 截图 / 清除」只作用于当前槽；每个槽可单独放图，也可只放一张。
- 每个目标只放一张图也能正常跳过；放 2/3 张时任一识别到就自动点击匹配区域中心，适配不同明暗背景。
- 目标 1 点击成功后自动识别目标 2，目标 2 成功再识别目标 3；只设目标 1 时点击后重新等待，未设置的后续目标自动跳过。
- **顺序**：严格按 1 → 2 → 3 识别；**随机**：每次从尚未点击的目标中随机选一个识别。
- 支持为剧情跳过绑定全局快捷键（默认 `F9`，仅支持键盘，与图片识别截图键 `F8` 区分）；通过快捷键或显示键菜单开启 / 关闭时，屏幕正中央会弹出汉字提示。

![跳过剧情](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/story-skip.png)

### 右侧按键设置（短按 / 长按 / 双击）

- **按键名称**：显示在悬浮层按键上。
- **绑定按键 · 短按**：点击录制框后按下任意键；右键可选择鼠标左 / 右 / 中 / 滚轮。
- **长按触发**：独立开关，可绑定长按按键并设置 200 ~ 3000 毫秒触发时长，默认 **2000 毫秒（2 秒）**，短按不会触发长按；长按使用独立后台计时器，按住达到时长立即触发，不依赖松开，松开会停止计时并释放按键。
- **双击触发**：在 300 ms 内连续两次抬起触发独立绑定，与短按、长按互斥，各自独立保存。
- **按键尺寸**：滑块或数字框调节，默认 **152 px**，范围 40 ~ 360 px。
- **按键不透明度**：10% ~ 100%，文字和 PNG 图标一起生效。
- **按键图标**：选择透明 PNG，图片复制到 `key_images\`；没有图片时显示名称。
- **跟随隐藏模式隐藏**：关闭后，隐藏状态下该按键仍然可见。
- **联动保持长按**：选择一个对象控件（摇杆或其他虚拟按键）；松开本键时如果对象控件仍在操作，本键继续保持按下，对象停止后自动松开。例：操控摇杆时按住 Shift，松开手指后 Shift 保持，摇杆停止后自动恢复。
- **新增 / 删除按键**：每个模式独立管理，删除前二次确认。

![按键设置](https://cdn.jsdelivr.net/gh/ganzhong2/MobileUI-Config@main/screenshots/editor.png)

### 虚拟手柄页

标题栏切换到虚拟手柄页后，配置根与虚拟按键页完全独立：

- 内置三套经典布局预设，可整套一键添加，也可逐个添加单个按键（三套共用同一组位码，仅符号与显示名按厂商区分）：
  - **微软 Xbox**：A / B / X / Y、方向键、左右摇杆、LS / RS、视图键（Back）、菜单键（Start）、LB / RB、LT / RT；
  - **索尼 DualShock**：△ / ○ / × / □、方向键、左右摇杆、L3 / R3、分享键（Back）、选项键（Start）、L1 / R1、L2 / R2；
  - **任天堂 Switch Pro**：A / B / X / Y、方向键、左右摇杆、LS / RS、+（Start）/ −（Back）、L / R、ZL / ZR。
- 弹窗内按厂商人体工学布局排列按键，左侧品牌布局名称、右侧按键说明；添加到手机画面时不显示说明文字。
- 「ViGEmBus / HID」两个驱动通道互斥，同时只能开启一个；手柄按钮、扳机、摇杆轴分别上报到对应虚拟手柄目标。
- 摇杆大小、方向键尺寸、透明度等参数在手柄页内独立调整，与按键页摇杆配置互不影响。

### 托盘与后台运行

- 点窗口关闭按钮始终**隐藏到托盘**，不退出程序；最小化仍保留任务栏图标；最大化使用 Windows 原生最大化。
- 托盘菜单：打开设置界面、环境状态 / 悬浮层状态、重新检测串流、开机后台待命、游戏结束后自动退出、退出。
- 游戏退出后程序继续驻留托盘；主动退出请使用托盘菜单「退出」。
- **单实例运行**：重复启动 exe 会通知已有实例打开设置，不会产生多个悬浮层。

### 运行时输入安全

- **游戏在前台**：才加载悬浮层、安装鼠标 / 触摸辅助钩子、执行图片识别 / 内存扫描 / 剧情跳过，并注册截图快捷键。
- **游戏在后台或最小化**：自动关闭悬浮层、卸载输入钩子、暂停自动切换 / 内存扫描 / 剧情跳过、注销快捷键，并释放所有已按下的键盘和鼠标状态。
- 游戏回到前台：重新按当前设置启用；若设置窗口正在前台则继续保持暂停。
- 鼠标转触摸、双指缩放这类全局输入钩子只在游戏前台安装，停留在桌面时不挂全局鼠标钩子。
- 屏蔽物理键鼠功能不会拦截 `Alt+F4` 退出游戏；注入的事件携带内部标记，输入辅助钩子会放行，不会二次拦截。
- 程序不安装常驻全局键盘钩子；仅在虚拟手柄页开启「屏蔽物理键鼠」且游戏处于前台期间临时安装低级键盘钩子，切后台即卸载。后台和退出时强制释放 Win、Ctrl、Shift、Alt、L 与鼠标按键，避免修饰键残留导致锁屏等异常。
- 启动前会检查游戏是否已在运行，已在运行或刚发出启动请求时不会重复启动。

## 从源码编译

### 前置条件

- **标准版**：Windows 自带 .NET Framework 4.8 的 `csc.exe`（无需 Visual Studio、无需第三方包）。
- **独立版**：安装 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)，`dotnet --version` 可正常输出版本号。

### 一键脚本

```powershell
# 标准版（.NET Framework 4.8，依赖系统运行时，产物较小）
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-standard.ps1

# 独立版（.NET 8 自包含单文件，内置运行时）
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-selfcontained.ps1
```

两个脚本都会把产物输出到 `dist/v1.0.0/`，并把 `libs/ViGEmClient.dll` 复制到发布目录。详见 [docs/build.md](docs/build.md)。

> 注意：标准版使用 .NET Framework 4 自带 csc 编译器，对应 C# 5 语法面，源码不要使用 `?.`、表达式成员、`nameof`、内联 `out` 变量等更高版本语法。

## 数据文件

| 文件 / 目录 | 说明 |
| --- | --- |
| `MobileUIConfig.xml` | 当前正在编辑项目的方向、模式、按键、不透明度、联动、摇杆、视角、自动模式、位置、串流名单、后台设置（运行时生成，不进仓库） |
| `games/` | 每个已保存游戏一份完整 XML 及其 `assets/` 资源目录（运行时生成） |
| `key_images/` | 当前游戏专属资源目录下的透明 PNG 按键图标（运行时生成） |
| `sounds/` | 当前游戏专属资源目录下的按键反馈音效（运行时生成） |
| `feature1_1.png` ~ `feature12_3.png` | 各图片项目的特征截图（项目 1~12、槽位 1~3，运行时生成） |
| `skip1_1.png` ~ `skip3_3.png` | 自动跳过剧情目标 1~3 的参考图（运行时生成） |
| `*.mobui` | 导出的配置分享包（配置 + 全部图片 + 特征截图 + 剧情跳过图） |
| `MobileUIConfig.log` | 启动、串流检测、游戏退出、保存和异常日志 |

所有修改自动保存，项目栏显示保存状态；配置文件损坏时会自动备份为 `MobileUIConfig.xml.broken-时间戳` 并恢复默认配置。
